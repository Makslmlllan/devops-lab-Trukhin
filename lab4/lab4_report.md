# Лабораторная работа №4  
## Разработка сайта с использованием MkDocs

---

## Цель работы

Изучение инструмента MkDocs для создания статических сайтов и публикация сайта с использованием GitHub Pages.

---

## Репозиторий

Репозиторий со всеми файлами:

---

## Сайт

Сайт, опубликованный с использованием GitHub Pages:  
https://makslmlllan.github.io/devops-lab-Trukhin/

---

## Используемые технологии

- MkDocs  
- Material for MkDocs  
- Markdown  
- GitHub Pages  

---

## Описание сайта

В рамках лабораторной работы был разработан статический сайт проекта SmartDebt — мобильного приложения на основе блокчейн-технологий для управления долговыми обязательствами между физическими лицами.

Сайт включает следующие разделы:
- Главная страница  
- О проекте  
- Исследование  
- Обо мне  
- Контакты  

---

## Основные возможности сайта

- Навигация между страницами  
- Использование темы Material  
- Использование Markdown-разметки  
- Добавление изображений  
- Публикация в интернете через GitHub Pages
