# Лабораторная работа №4  
Разработка сайта с использованием MkDocs

Цель работы

Изучение инструмента MkDocs для создания статических сайтов и публикация сайта с использованием GitHub Pages.

Репозиторий

Репозиторий со всеми файлами:  
https://github.com/makslmlllan/devops-lab-Trukhin

Сайт

Сайт, опубликованный с использованием GitHub Pages:  
https://makslmlllan.github.io/devops-lab-Trukhin/

технологии

- MkDocs  
- Material for MkDocs  
- Markdown  
- GitHub Pages  

Описание сайта

SmartDebt — мой проект магистратуры, это мобильное приложение на основе блокчейн-технологий для управления долговыми обязательствами между физическими лицами.

Сайт включает следующие разделы:
- Главная страница  
- О проекте  
- Исследование  
- Обо мне  
- Контакты  

Основные возможности сайта

- Навигация  
- Использование темы Material  
- Использование Markdown-разметки  
- Добавление изображений  
- Публикация в интернете через GitHub Pages  

Результат

В результате работы был разработан статический сайт с использованием MkDocs и опубликован в сети Интернет с помощью GitHub Pages.

Все требования лабораторной работы выполнены:
- создан сайт с несколькими страницами  
- использована тема Material  
- реализована навигация  
- сайт опубликован и доступен по ссылке  

Вывод

В ходе выполнения лабораторной работы были получены практические навыки работы с MkDocs, Markdown-разметкой и публикацией сайтов с использованием GitHub Pages.
